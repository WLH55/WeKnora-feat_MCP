# 口播文稿 v2 · 从零配置版（对应素材 0~7）

> 逐字稿 v1（7 镜头演示版）已作废。本版对应 8 段配置实拍素材。
> 用法：素材录好后量各段时长 → 按需增删下面每段的话 → edge-tts 生成对齐。

| 素材 | 口播初稿 | 预估时长 |
|------|---------|---------|
| 00-部署初始化 | 整套系统用 Docker Compose 一键拉起，全部跑在我们自己的服务器上——私有化部署，数据不出内网。模型接 DeepSeek、Qwen 这些国产大模型的 API，嵌入模型单独可配，全部就绪只用了几分钟。 | ~20s |
| 01-创建空间 | 第一步，创建部门空间。平台内置四级角色：所有者、管理者、编辑、访客——谁能看什么、谁能改什么，从建空间这一刻就开始管。 | ~15s |
| 02-建库解析 | 第二步，创建知识库，上传排障复盘、接口约定这些文档，系统自动完成解析、分块、向量化。之后所有的问答，都基于这批知识来回答。 | ~18s |
| 03-邀请成员 | 第三步，邀请成员、分配角色。成员和角色管理是所有者专属权限，防止权限被随意改动；新同事进来默认最小权限。 | ~15s |
| 04-钉钉同步 | 第四步，钉钉同步——这是我们的第一个二次开发。WeKnora 官方只支持飞书、Notion、语雀，我们基于它的连接器框架自研了钉钉数据源：整库同步、按链接同步单篇都支持，文档自动入库，没有人手工搬运。 | ~22s |
| 05-分配APIKey | 第五步，按人分配 API Key——第二个二次开发。原生接口不区分人，谁拿到钥匙谁有全部权限；现在每位同事一把独立 Key，能力逐项勾选、知识库范围可限定——AI 和人同权，没有越权旁路。 | ~20s |
| 06-配置MCP | 第六步，把 WeKnora 的 MCP 接口接进本地 AI 编码工具。每个客户端携带自己的 Key 接入：干活时能把排障经验自动沉淀进知识库，需要时又能先查公司知识库再回答——双向打通。 | ~20s |
| 07-Langfuse看板 | 最后一步，Langfuse 全链路观测：每次调用、token 消耗、模型成本，一屏看清。到这里，从知识进料、权限管控到使用观测的完整链路就搭好了。 | ~18s |

> 合计约 148s（2 分半）。素材若更长，口播保持不变、画面加速即可；总片长目标 3~4 分钟。

## 录制注意（8 段通用）

1. 每段单独一个文件，命名 `00-部署初始化.mp4` ~ `07-Langfuse看板.mp4`，与上表对应
2. 头尾各留 2~3 秒静止余量
3. **敏感信息务必遮挡**：钉钉 AppKey/AppSecret、API Key 明文、服务器 IP——录屏前把输入框内容换成演示值，或后期打码
4. 鼠标放慢、点击前停半秒；打字内容提前放记事本粘贴
