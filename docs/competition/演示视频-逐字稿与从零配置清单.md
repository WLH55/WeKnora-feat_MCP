## 二、从零配置清单（按依赖顺序，做完一步勾一步）

### 第 0 步 · 部署与初始化

- [ ] `docker compose up -d` 拉起主栈（app / frontend / postgres / redis / docreader / mcp-server）
- [ ] 需要 Langfuse 自建则加 profile：`docker compose --profile langfuse up -d`（ClickHouse 首次迁移约 1–2 分钟；复用主栈 pg/redis，新增内存约 1–1.5 GB）
- [ ] `.env` 配置模型 API Key（DeepSeek/Qwen 等）；如接 Langfuse：填 `LANGFUSE_HOST` / `LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY`（自建栈 HOST 填 `http://langfuse-web:3000`）
- [ ] `docker compose up -d app` 重启后，`docker compose logs app | grep Langfuse` 看到 `[Langfuse] enabled` 即接入成功
- [ ] 浏览器打开 WeKnora，注册管理员账号；空间设置里配置推理模型 + 嵌入模型，各做一次连通性测试

### 第 1 步 · 创建空间

- [ ] 创建部门空间（如"研发中心"）。注册用户默认有个人空间，部门空间用于演示 RBAC
- [ ] 熟记四级角色（演示话术要用）：**所有者**（成员/邀请/API Key/空间配置）> **管理者**（管任何资源+基础设施）> **编辑**（管自己创建的资源）> **访客**（纯只读 + 可对话，不能建知识库/智能体）
- [ ] 注意：邀请成员、管理 API Key 是**所有者专属**，演示时用管理员账号

### 第 2 步 · 创建知识库 + 上传文档 + 解析

- [ ] 新建知识库：文档型、RAG 模式，命名如"研发排障知识库"
- [ ] 准备 5–10 篇演示文档（Markdown/PDF）：排障复盘 2–3 篇、接口约定 1–2 篇、部署手册 1 篇。**重点排障文档的标题和内容措辞，要与演示提问的措辞对齐**（如《网关 502 排查复盘》，提问就用"网关 502 之前怎么解决的"）
- [ ] 上传 → 等待解析完成（列表状态从"解析中"变"已完成"；提前半天做，别在录制时等）
- [ ] **命中验证（必做）**：对话页按演示问法各提问 3 次，确认引用稳定命中目标文档；命中不稳就改文档标题/增加关键词条目

### 第 3 步 · 邀请成员（准备两个演示账号）

- [ ] 空间成员管理 → 邀请成员（邀请码或链接），邀请：
  - **同事 A**：角色"编辑"（用于展示正常协作）
  - **新人小 B**：角色"访客"（用于越权演示）
- [ ] 用无痕窗口分别登录两个账号各一次，确认可进空间
- [ ] 小 B 登录后尝试"创建知识库"应不可见/不可用——这一幕可作为权限演示的 Web 侧佐证

### 第 4 步 · 钉钉数据源（二开①）

- [ ] 钉钉开放平台创建**企业内部应用**，拿到 AppKey/AppSecret，申请文档读权限；操作人按手机号配置（连接器自动解析 手机号 → userid → unionId）
- [ ] WeKnora → 空间设置 → 数据源 → 添加 → 选"钉钉" → 填 AppKey/AppSecret → 测试连接
- [ ] 选择要同步的钉钉知识库范围，绑定目标知识库（可单独建一个"钉钉同步"知识库，画面更干净）
- [ ] 手动触发一次同步，确认文档出现在知识库列表
- [ ] **录制脚本**：镜头 2 的动作是"钉钉里打开/新建一篇文档 → 切 WeKnora 数据源页点同步 → 文档出现"。提前排练一遍掐秒；同步超过 30 秒就剪辑加速
- [ ] 备用：把整段同步过程预录一段，现场失败就切预录素材

### 第 5 步 · 分配 API Key（二开②）

- [ ] 空间设置 → API 集成 → 创建 API Key（所有者专属）。发两把：
  - **自己的 Key**：能力勾 `检索知识库(retrieve)` + `对话能力(chat)` + `写入知识库内容(ingest)`，知识库范围选研发知识库 → 供 MCP 沉淀 + 检索用
  - **新人小 B 的 Key**：只勾 `retrieve`，知识库范围**不包含**核心 ADR/排障库（只给公开库）→ 供越权演示用
- [ ] Key 明文只显示一次，立刻存好
- [ ] 验证：用小 B 的 Key 发起检索核心库的请求，应 403 或检索不到（这就是镜头 5 的"被拒"画面）

### 第 6 步 · 配置 MCP 工具

- [ ] **方式 A · 单机 stdio**（最简单）：本机装 [uv](https://docs.astral.sh/uv/)，客户端配置指向仓库 `mcp-server/` 目录：
  ```json
  {
    "mcpServers": {
      "weknora": {
        "command": "uv",
        "args": ["--directory", "D:/AI/WeKnora-feat_MCP/mcp-server", "run", "run_server.py"],
        "env": {
          "WEKNORA_BASE_URL": "http://localhost:8080/api/v1",
          "WEKNORA_API_KEY": "<自己的 Key>"
        }
      }
    }
  }
  ```
- [ ] **方式 B · 共享网关 http**（更能体现"按人授权"，推荐镜头 4/5 用）：Docker 栈已含 mcp-server（8082 端口，`--transport http`），客户端直接连：
  ```json
  {
    "mcpServers": {
      "weknora": {
        "type": "http",
        "url": "http://localhost:8082/mcp",
        "headers": { "Authorization": "Bearer <个人 Key>" }
      }
    }
  }
  ```
  每个客户端带各自 Key，per-key 能力位、知识库白名单端到端生效——镜头 5 换成小 B 的 Key 即现场复现"被拒"
- [ ] 验证：客户端里确认 weknora MCP 显示已连接，工具列表出现（`hybrid_search`、`create_knowledge_from_text`、`chat` 等）
- [ ] 试运行两连：①"把这段经验沉淀进知识库"（走 `ingest`）→ 知识库出现新文档；②"这个报错之前怎么解决的"（走 `retrieve`）→ 带引用回答

### 第 7 步 · Langfuse 看板

- [ ] 打开 Langfuse（自建 `http://localhost:3000` 或 Cloud），注册/登录
- [ ] Project Settings → Models：给自己用的模型配置单价（每 1K token），看板会自动核算费用——镜头 6 说"模型成本可算"就有画面支撑
- [ ] **预热数据**：提前跑十几次问答/检索/解析，让 Traces 页有量、Dashboard 有曲线（录制时看板不冷场）
- [ ] 熟悉一条 trace 树：HTTP trace → 工具/解析 span → generation（prompt/completion tokens），知道点哪里

### 第 8 步 · 素材预埋与环境整理

- [ ] 要粘贴的文本全部提前放记事本（如镜头 4 让 AI 沉淀的"经验"文字），录制时粘贴不手打
- [ ] 浏览器：缩放 110–125%、深色主题统一、只留演示要用的标签页
- [ ] Windows 开启勿扰（关通知弹窗）；清理桌面图标
- [ ] 降级预案：镜头 2（钉钉同步）与镜头 4（MCP 沉淀/检索）各预录一段备用
- [ ] 完整彩排 3 遍并掐表，总时长压在 2:50–3:00
