## 一、PPT 大纲（19 页，讲 18-20 分钟含 demo）

### P1 封面
- 标题：《让企业知识成为资产：基于 WeKnora 的 AI 提效实践》
- 副标题：研发 / 产品 / 管理 三场景落地 · 开源底座 + 自研扩展

### P2 痛点共鸣（30 秒）
- 三连问配图：知识在哪？--钉钉、群聊、离职员工的电脑里
- 关键句："文档都在，但知识不可检索、不可推理、不可度量，所以不是资产"

### P3 方案总览（1 分钟）
- 一张架构图：钉钉/文档/IM -> WeKnora 知识中枢（RAG/Wiki/RBAC/Langfuse）-> 三类角色入口
- 强调四点：私有化部署（数据主权）、开源底座+自研扩展、全链路可观测、**部门空间隔离（谁能看什么，有工程答案）**

### P4 为什么选 WeKnora（1 分钟）
- 开源可私有化（Tencent 开源 MIT）vs SaaS 知识库对比表
- 模块化：LLM/向量库/存储/数据源全可插拔
- 关键句："自研力量不造轮子，聚焦公司场景"

### 第三幕：管理场景（P11-P14）

### P11 案例三痛点（30 秒）
- 知识随人流失；沉淀不可见；员工找知识靠熟人
- 关键句："公司协作主平台就是钉钉，这个场景就是我们公司的现实"

### P12 案例三方案（1 分钟）
- 全链路图：钉钉文档 --①自研连接器--> 知识中枢 --③IM 机器人--> 员工；②Wiki 沉淀；④Langfuse 观测
- 强调：连接器是补齐官方预留空缺的自研工作

### P13 【现场 Demo 3】钉钉知识资产中枢（5 分钟）
- 按演示脚本执行（核心画面：钉钉新建文档自动同步 + 群机器人带引用回答 + Langfuse 仪表盘）

### P14 部门空间隔离与权限治理（1 分钟 · 管理层重点页）
- 一张图：公司组织 -> 工作区（研发中心/产品部/全员）-> 四层角色矩阵（viewer/contributor/admin/owner）
- 三个关键句：
  - "不同部门不同空间，文档默认隔离；跨部门走共享空间，且共享绕不过源空间权限"
  - "AI 与人同权：AI 编码助手、钉钉机器人检索到的，只是提问者有权看的知识--无旁路"
  - "越权尝试全量审计（rbac.access_denied），Langfuse trace 里连提问者角色都可见"
- 补充一句：账号支持对接公司统一身份认证（OIDC/SSO）--员工用公司账号登录，离职自动失效（平台内置，配置即用）

### P15 安全与治理（30 秒）
- 私有化 + RBAC + 审计日志 + API Key 管控 + AES 加密
- "所有数据在公司自己服务器上"

## 二、两周冲刺排期（按比赛前 14 天倒排）

### 第 1 周：数据与底座

| 天 | 任务 | 产出/验收标准 |
|----|------|--------------|
| D1 | 虚构数据集"云梭科技"：研发线 40 篇（ADR/排障/复盘） | 文档写完并校对埋点（跨文档关联 + 暗知识） |
| D2 | 虚构数据集：产品线 25 篇（PRD/纪要/反馈）+ 全员 15 篇 | 数据集全部完成（~80 篇） |
| D3 | 导入 WeKnora、建工作区/知识库、调检索阈值；**搭建权限演示环境**：建 3 个空间（研发中心/产品部/全员）+ 各角色账号（Owner/Admin/Contributor/Viewer）+ 共享空间只读共享 + scoped API Key 按 role 区分 | 三个知识库检索命中率预演验证（每问题 3 次）；**权限矩阵验证：Viewer 检索 ADR 被拒、跨空间不可见、共享库只读** |
| D4 | **钉钉测试组织搭建**：注册组织、建企业内部应用、申请文档权限、凭证验证 | API 能拉到文档列表（关键里程碑，不通过则启动降级预案） |
| D5 | **钉钉连接器开发 day1**：client.go（鉴权/文档列表/文档拉取）+ types.go | 能列出知识库空间与文档 |
| D6 | **钉钉连接器开发 day2**：connector.go（Validate/ListResources/FetchAll）+ 注册到框架 | Web UI 数据源页出现钉钉选项，能选空间并全量同步 |
| D7 | 缓冲/还债：修 D5-D6 遗留问题；Wiki 预生成启动（跑通后挂后台） | 连接器端到端同步链路稳定 |

- **D11 Gate**：串讲 ≤20 分钟 -> 继续；超时 -> 砍案例二的 Wiki 增量环节（保留图谱 + 问答）
