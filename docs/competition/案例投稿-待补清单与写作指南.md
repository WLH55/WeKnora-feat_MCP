## 一、待补清单（按优先级排序）

### 1.【最紧迫】④ 收益的全部数字

正文的 ④ 表格目前只有公式框架，没有一个真实数字。这是模板的硬性要求（"效果必须货币化"出现两次），没有数字等于缺一整段。

**需要你收集的基础数据：**

| 数据项 | 用在哪 | 去哪拿 |
|--------|--------|--------|
| 部门人数 | ④ 各收益行 | 按实际 |
| 每人每周被同事重复问题打断的次数、单次耗时 | 答疑打断收益 | 自己估 + 问两个同事验证 |
| 每人每天找文档的耗时（现在 vs 用知识库后） | 检索提效收益 | 自己估 |
| 每年新人数、原独立上手月数、预期缩短月数 | 新人提速收益 | 按实际 |
| 人力时薪口径 | 全部收益行 | 问 HR，或按"月薪 ÷ 21.75 ÷ 8 × 1.4"估全成本 |
| 服务器费用（内网虚拟机 ≈ 0 边际成本，或云主机月费） | 成本行 | 按实际 |
| 模型 API 月均花费 | 成本行 | 模型平台账单 |
| 二开投入人日（钉钉连接器 + 按人 API Key） | 成本行 + ③ | 按实际 |

### 2. ①"过去的处理方式"需要核对

正文 ① 我补写了四条（靠问人 / 靠归档 / 靠带人 / 公网 AI 用不了），是从你痛点表格的暗示推写的。**逐条核对是否符合你们部门实际**，不符的改掉，缺的补上（比如你们以前是否真维护过 Confluence/Wiki 然后荒废了——如果有，是很强的对比素材）。

### 3. ③ 二开耗时

两个二开（钉钉文档同步连接器、按人 API Key）各花了多少人日，填进 ③ 和 ④ 成本行。

### 4. ⑥ 选型对比

如果真的对比评估过其他方案（公网 SaaS、Confluence、自研等），把名字写进去；**没对比过就删掉那段，不要编**。

### 5. ①③⑥ 里的散点

- ① 开头：部门名称、岗位
- ① 货币化目标里的 X/Y/Z（每周被打断小时数 → 目标）
- ⑥ 后续计划（推广部门、Langfuse 观测、运维 SOP 等）

## 二、六段式模板写作要领

**总原则：模板要的是"我的故事"，不是"产品介绍"。** 主角是你，WeKnora 只是工具。每一句功能描述都要能回答"所以我用它做了什么"。动词开头、动作主体是"我/我们"（"第一步：我建了部门空间"），而不是功能说明（"空间里有四种角色"）。

### ① 挑战

公式：**场景 → 痛点 → 过去怎么办 → 货币化目标**

- 痛点要写"具体表现"，不写抽象概念。"跨部门协作要先花半天对齐常识" ✓；"知识管理效率低" ✗
- "过去怎么办"是和后面形成对比的关键——旧方法的徒劳衬托新方法的价值
- 货币化目标写方向 + 幅度即可（"答疑量降 70%"），精确数字留给 ④

### ② 解决方案

- 按动手顺序写步骤（第一步~第五步），每步"我做了什么 + 截图佐证"
- 模板要求方案必须含 AI 技术应用——正文 2.5 已单列"用到的 AI 技术"清单，确保评委一眼看到，别删
- 产品功能细节放附录（正文已这样处理），有篇幅限制先砍附录

### ③ 新问题与解决（你的差异化加分项）

最加分的结构：**问题 → 为什么难（官方不支持/原生能力缺失）→ 我怎么解决 → 结果**

你的两个二开天然符合：
1. 官方不支持钉钉文档同步 → 调研钉钉开放平台 API（无导出接口、无变更事件）→ 自写 block→Markdown 转换器 + 修改时间轮询 → 基于连接器框架二开，稳定运行
2. API Key 不区分人、有越权风险 → 二开按人 API Key 透传与校验 → "AI 同人同权"

评委最怕"拿开源产品截图交差"，这两个二开证明你不只是用户、是改造者——答辩时重点讲这段。

### ④ 收益（最关键）

可信的数字 = **公式 + 保守假设**，不是一个拍脑袋的总数。

> **年化节省 = 人数 × 频次 × 单次节省时间 × 时薪 × 周期**

算例（数字是编的，代入你的真实值）：
部门 10 人，每人每周被重复问题打断 5 次、每次 15 分钟
→ 10 × 5 × 0.25 小时 × 48 周 = **600 小时/年**
→ 时薪 60 元（全成本）≈ **3.6 万元/年**

让数字"可防御"的三个技巧：
1. **每项写明计算口径**（④ 表格已留"计算口径"列），评委追问能当场复算
2. **分"已发生"和"预估"**：钉钉同步省的人工搬运是已发生，新人提速是预估，分开标注
3. **成本也要算，给出净收益**："投入 X 万、年省 Y 万"比只说"省了 Y 万"可信一个量级

### ⑤ 推广场景

每条用"**谁 + 什么痛 + 这套方法怎么解**"一句话带过。你有实测截图的（产品 Wiki 图谱、AI 客服内嵌）写"已验证"最有说服力。

### ⑥ 其他

放不好归类的加分项：安全合规（私有化、加密、审计）、成本透明、后续计划。
