## 案例一 · 研发知识中枢 + AI 编码助手（5 分钟）

**角色扮演设定**：你是云梭科技一名新入职后端开发，周一早上接到一个线上告警。

| 时间 | 画面/操作 | 讲述要点 |
|------|----------|---------|
| 1:00-1:30 | 终端打开 Claude Code，输入："网关昨天报 502，之前有人处理过吗？怎么解决？" | "我是新人，我不想打断 mentor--我先问 AI" |
| 1:30-2:30 | **核心画面**：Claude Code 自动调用 weknora MCP 工具检索 -> 流式输出答案，答案中带引用来源（ADR-011 或值班复盘 #47） | "注意三点：一，它检索的是**公司内部知识库**，不是互联网；二，答案**带引用**，我可以点开看原始复盘；三，这背后是我们**自研的 MCP Server**，让任何 AI 编码工具都能接入公司知识" |
| 2:30-3:10 | 追问："按这个方案，帮我在 gateway 服务里写修复代码" -> 生成代码 | "不止回答问题，还能直接按公司的历史结论干活" |
| 3:10-3:40 | **越权即拒**：切到 Viewer 账号（新人员工）的 Claude Code，问"支付网关核心架构的 ADR 决策是什么" -> AI 检索不到或明确答"无权限访问" | "AI 和人同权--新人能看到的知识 AI 才能检索。不存在 AI 泄密的旁路" |
| 3:40-4:20 | **对比实验**：输入 `/mcp` 关闭 weknora 工具，重复第一个问题 -> AI 泛泛而谈/答非所问 | "关掉知识库，同一个模型立刻变平庸--价值在知识，不在模型" |
| 4:20-4:50 | 切到 Langfuse，展示刚才调用的 trace：检索了哪些 chunk、token 消耗、耗时、**TenantRole 字段** | "每一次知识调用都被记录，连提问者角色都在 trace 里--知识的使用第一次可度量、可审计" |
| 4:50-5:00 | 回到终端收尾 | "老员工少被打断，新人少走弯路，排障经验一次沉淀全组复用" |

**预演检查点**：
- [ ] Claude Code 的 weknora MCP 连接正常（`claude mcp list` 显示 ✓ Connected）
- [ ] 知识库中"网关 502"复盘文档已导入且检索命中稳定（预演 3 次确认）
- [ ] **Viewer 账号提前建好并配好独立 MCP 配置**（scoped API Key 只授权研发公开库，验证过问 ADR 确实拒）
- [ ] 关闭 MCP 后的"翻车"效果稳定复现（模型确实答不出内部问题）
- [ ] Langfuse trace 已有历史数据，展示时不冷场；确认 trace 里 TenantRole 字段可见

## 案例二 · 产品决策资产库 + Wiki 自动蒸馏（5 分钟）

**角色扮演设定**：你是云梭科技产品经理，明天要评审"消息模块 V3.0 改版"。

| 时间 | 画面/操作 | 讲述要点 |
|------|----------|---------|
| 1:00-1:30 | Web UI 进入产品知识库，展示 50 份原始文档列表（PRD/纪要/反馈，命名混乱） | "两年的产品文档长这样--都在，但没人能用" |
| 1:30-2:20 | 切到 Wiki 浏览器：展示已生成的结构化 Wiki（互链页面树） | "Agent 把 50 份散乱文档自动蒸馏成结构化知识库--这是生成好的，我们看现场增量" |
| 2:20-3:00 | **核心画面**：上传一份新文档"V3.0 消息改版预审纪要.md" -> 触发 Wiki 增量生成（等待期间切下一页讲图谱） | "新文档进来，Wiki 自动更新关联关系" |
| 3:00-3:50 | **核心画面**：打开知识图谱，搜索"离线模式"，节点展开：关联 PRD-2.3、评审纪要、用户反馈池 3 条 | "知识图谱把决策网络画出来了--点'离线模式'，能看到它关联的讨论、反馈和最终砍掉它的决策" |
| 3:50-4:30 | **跨部门隔离对照**：右上角切换到研发空间账号 -> 产品 Wiki 不在列表；打开共享给研发的"API 文档库"（只读），试图点"编辑"被隐藏/拒绝 | "产品部的裁撤讨论、定价策略，研发看不见；研发该拿的 API 文档，通过共享空间只读给到他--横向协作有通道，纵向隔离有墙" |
| 4:30-4:50 | 回到问答界面提问："离线模式当初为什么砍掉？" -> 回答引用纪要原文（"结论：维护成本 > 收益，V2.0 移除"） | "评审会上再争论这个，30 秒溯源到当时的讨论记录--产品决策不再失忆" |
| 4:50-5:00 | 收尾 | "文档从死档案变成可推理的知识网络，评审前先问 Agent'这个需求历史上讨论过什么'" |

**预演检查点**：
- [ ] Wiki 已完整预生成（含"离线模式"关联链路），知识图谱节点渲染正常
- [ ] 增量上传的新文档提前测试过 Wiki 更新流程，等待时间可控（<2 分钟）
- [ ] "离线模式"问答的引用命中稳定（预演 3 次，检索阈值已调优）
- [ ] **研发空间账号已提前建好，验证过：产品 Wiki 不可见 + 共享 API 库只读可开**（编辑入口隐藏）
- [ ] 图谱页面前一天缓存加载，避免现场首开卡顿

## 案例三 · 钉钉企业知识资产中枢（5 分钟 · 自研主打）

**角色扮演设定**：你是云梭科技的老板/CTO，想知道公司的知识资产 status。

| 时间 | 画面/操作 | 讲述要点 |
|------|----------|---------|
| 1:00-1:30 | 打开钉钉（测试组织），展示"云梭科技"知识库空间：周报、制度、部门文档 | "公司真实的协作在钉钉上--问题是文档在这里，知识却没沉淀" |
| 1:30-2:20 | **核心画面**：现场在钉钉新建一篇文档《新人入职避坑指南.md》（输入两段内容）-> 切到 WeKnora 数据源页 -> 点击"立即同步" -> 文档出现在知识库列表 | "我们自研了钉钉数据源连接器--WeKnora 官方预留了接口没人实现，我们补上了。文档自动入库，无需任何人手动搬运" |
| 2:20-3:20 | **核心画面**：钉钉群里 @知识机器人："新员工入职报销流程是什么？" -> 机器人流式回复，带引用来源 | "员工零门槛--不装新 App、不改习惯，在天天用的钉钉里 @机器人 就行。这是 Stream 模式长连接，无需公网服务器" |
| 3:20-4:10 | 切到 Langfuse 仪表盘：展示近一周问答量曲线、Top 热门知识、token 成本 | "老板视角：公司知识资产第一次可度量--哪些知识被问爆了、哪些文档在吃灰、AI 成本多少，一屏看清" |
| 4:10-4:40 | **权限压轴戏**：打开"全员知识库"空间成员管理页（四类角色成员清单）-> 切到审计日志，指给评委看 `rbac.access_denied` 越权拦截记录 | "谁能看什么，逐级管控。谁来过、谁被拦了，全有记录--这就是企业敢用的治理底座" |
| 4:40-5:00 | 收尾回到 Docker 页面 | "最后强调：所有数据在公司自己的服务器上。知识归公司，不归任何 SaaS" |

**预演检查点**：
- [ ] 钉钉连接器同步链路端到端跑通（新建文档 -> 同步 -> 入库 <1 分钟）
- [ ] IM 机器人 Stream 连接稳定（手机热点环境测试过）
- [ ] Langfuse 有近一周的模拟使用数据（预生成，仪表盘不冷场）
- [ ] **审计日志里已预埋 `rbac.access_denied` 记录**（彩排时用 Viewer 账号触发几次越权请求，确保演示时有数据可指）
- [ ] **降级预案就绪**：连接器演示失败 -> 切换"钉钉导出文档批量导入"路径，话术："同步方式有多种，今天现场展示手动模式"（不慌乱、不冷场）
- [ ] 备用：连接器同步过程录屏（以防 API 现场抽风）

## Q&A 预案（3 分钟）

| 可能提问 | 应答要点 |
|---------|---------|
| "数据安全吗？文档都传到哪了？" | 全私有化部署，文档/向量/日志都在公司服务器；LLM 推理层可切 Ollama 本地模型实现全离线，今天 demo 只是配置选择 |
| "不同部门的知识会互相看到吗？AI 会不会泄密？" | 不会。部门映射到独立工作区，空间间默认隔离；跨部门走共享空间且不能绕过源空间 RBAC；AI 调用（MCP/IM 机器人）与提问者同权限，刚才演示里 Viewer 问核心 ADR 就被拒了；越权尝试全部进审计日志 |
| "账号怎么管？员工离职了怎么办？" | 平台内置 OIDC/SSO 对接（配置即用）：员工用公司统一身份登录，首次自动建号，HR 禁用账号即全系统失效，不依赖人工记得删号；今天演示用的是本地邀请制账号 |
| "和直接用 ChatGPT/IMA 有什么区别？" | 三点：知识是公司私有的（通用大模型不知道）、答案带引用可溯源、使用情况可观测可管控 |
| "钉钉连接器多久能上生产？" | MVP 已完成核心链路，生产化还需：增量同步、权限映射、错误重试--预计 X 人周（按实际评估） |
| "成本多少？" | 私有化部署一台服务器 + LLM API 按 token 计费；Langfuse 看板可直接看到月度成本 |
| "为什么基于开源而不自研？" | 开源底座省掉 80% 造轮子（解析/检索/权限/观测），自研力量聚焦公司场景（MCP 接入 + 钉钉连接器）--这是工程判断力 |
